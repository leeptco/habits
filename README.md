# 🌱 Росток

План дня по матрице Эйзенхауэра и время на то, что помогает справиться с выгоранием: поиск работы, хобби, прогулки.
Напоминания идут через **Календарь iPhone**, так что информация не разбросана по куче приложений.

## Что умеет

- **План дня.** Есть два вида:
  - **Матрица Эйзенхауэра** — классическая сетка 2×2 с осями «срочно / важно».
  - **Расписание.** Можно по часам, а можно мягче: «утро · день · вечер». Показывает, насколько плотный день. Кнопка «Сдвинуть несделанное» переносит просроченные дела на ближайшее время.
- **Напоминания iPhone.** Невыполненные напоминания и сегодняшние события Календаря подтягиваются через команду в «Командах», без ручной выгрузки. Напоминания с флажком или высоким приоритетом сами попадают в нужный квадрат, остальные ты раскладываешь один раз, и Росток это запоминает. Если включить вторую команду, отмеченное в Ростке закрывается и в Напоминаниях.
- **Календарь iPhone.** Дела со временем и регулярные занятия отправляются в Календарь, и уведомления приходят оттуда.
- **Подсказки каждый день:** поиск работы, забытые хобби, прогулка, «дальше — больше», прошлые победы.
- **Занятия.** Таймер (с вопросом «как успехи?» каждые 30 минут через Календарь), всё вложенное время, сколько дней прошло с последнего раза. Рейтинг «что помогает больше всего» строится по самочувствию после занятия.
- **История.** Карта активности как у коммитов на GitHub: общая и по каждому занятию, серии дней подряд, детали по дню.
- **Instagram/YouTube.** Автоматизация «Команд» предлагает Росток при открытии приложения.

Пошаговые инструкции по «Командам» — в приложении, вкладка «Ещё».

## Как поставить на iPhone

1. На GitHub в репозитории: **Settings → Pages → Build and deployment**. Выбери ветку и папку `/ (root)`, нажми **Save**.
2. Через минуту появится адрес `https://<логин>.github.io/habits/`.
3. Открой его в Safari на iPhone → **Поделиться → На экран «Домой»**. Если есть переключатель «Открывать как веб-приложение», выключи его: тогда автоматизация из «Команд» и иконка будут работать с одними и теми же данными.

Запустить локально: `python3 -m http.server`, затем открыть http://localhost:8000.

## Свой сервер: аккаунт, синхронизация, уведомления

В папке `server/` лежит сервер Ростка (Node.js, без базы данных). С ним появляются:
- **аккаунт**: один логин на телефоне и компьютере, отметки синхронизируются; при одновременных изменениях побеждает более свежая правка каждой записи;
- **push-уведомления**: «Как успехи? Продолжаешь?» каждые 30 минут таймера, даже если Росток закрыт.

Как установить на VPS — в [DEPLOY.md](DEPLOY.md). Без сервера (например, на GitHub Pages) Росток работает как раньше, только на одном устройстве.

Локально: `cd server && npm install && node server.js`, затем открыть http://localhost:8080.
